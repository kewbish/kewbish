# Hi, I'm Emilie, though on the web I'm Kewbish.

I'm a researcher and software engineer interested in all things distributed systems.

I've worked at [OpenAI](https://openai.com) on the databases team, building distributed shadowing and synthetics testing frameworks, and at [Stripe](https://stripe.com) on the MongoDB team, saving tens of thousands in AWS costs by automating database assignments.

In my research, I'm interested in how we can automate verifying distributed and decentralized systems' correctness. I've explored areas like distributed systems security, formal verification, graph theory, and software engineering. I've worked as a Visiting Researcher at the [University of Cambridge](https://www.cst.cam.ac.uk/) on the [Kintsugi](https://github.com/kewbish/kintsugi) project and at [Sorbonne Université](https://www.sorbonne-universite.fr/) on a [formally-verified DB](https://dl.acm.org/doi/10.1145/3806077.3806696) project. I studied Honours CS at the [University of British Columbia](https://ubc.ca), where I've worked as an undergraduate research assistant on the [Specula](https://github.com/specula-org/Specula), [dcal](https://github.com/DistCompiler/dcal) and [PR-Issue Graph](https://github.com/ubcdlab/pr-issue-topology-project) projects.
